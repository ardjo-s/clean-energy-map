# Support

Use the repository's public channels:

- [Bug report](https://github.com/ardjo-s/clean-energy-map/issues/new?template=bug-report.yml)
- [Data correction](https://github.com/ardjo-s/clean-energy-map/issues/new?template=data-correction.yml)
- [Feature request](https://github.com/ardjo-s/clean-energy-map/issues/new?template=feature-request.yml)
- [Questions and discussion](https://github.com/ardjo-s/clean-energy-map/discussions)

Search existing issues first. Include a public atlas URL, stable facility identifier, browser version, and reproduction steps when relevant.

Security vulnerabilities and exposed credentials must be reported privately through [GitHub Security Advisories](https://github.com/ardjo-s/clean-energy-map/security/advisories/new), not through issues or discussions.
