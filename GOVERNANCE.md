# Governance

The project uses maintainer-led governance.

Maintainers set release scope, review contributions, enforce the evidence and publication contracts, and make final decisions when consensus is not reached. Decisions should favour verifiability, source quality, user safety, accessibility, and the smallest maintainable change.

Routine changes are decided through pull-request review. Material changes to methodology, licences, schemas, public calculations, or publication status require an issue or design note with evidence and a reversible migration path.

Maintainers may be added after sustained, constructive contributions and demonstrated care for the project's data and trust boundaries. The current owner may appoint or remove maintainers and will document material governance changes here.

Conflicts of interest must be disclosed. No contributor or sponsor receives authority to suppress source conflicts, uncertainty, limitations, or unfavourable data.
